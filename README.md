# 三星堆·掘

在线体验：https://cyzcyz669.github.io/sanxingdui/

原型 v0，还在改。你是考古队员：1986 年草棚夜里的抢救发掘，2020 年方舱里的多学科考古，用手指一层一层挖。本仓库只放网页发布文件。画面与声音的来源、授权、哪些是示意，写在页面内「来源」里（点页面底栏）。
